# قطة — Qatta 🐱

### مدير المصاريف المشتركة بالمجموعات | نسخة الويب

تطبيق ويب لتقسيم المصاريف داخل مجموعات مثل «قطة المنزل» و«قطة الاستراحة» و«قطة السفر». مبني بـ HTML/CSS/JavaScript بدون build step، ومربوط بـ **Firebase Authentication** و **Cloud Firestore**، ويُستضاف على **GitHub Pages**.

🔗 **https://alsufyaniz.github.io/qatta/**

---

## ✨ المزايا

**الحساب**
- التسجيل والدخول بـ **رقم الجوال + كلمة المرور** (الافتراضي) مع بريد اختياري
- أو بـ **البريد + كلمة المرور**، أو **Google**
- زر Enter يسجّل الدخول مباشرة
- ملف شخصي: الاسم، الجوال، البريد، لون الصورة الرمزية

**المجموعات**
- أي عضو ينشئ مجموعة باسم ورمز تعبيري (مع قوالب جاهزة)
- دعوة الأعضاء برابط أو رمز من 8 أحرف (مع مشاركة عبر واتساب)
- الصفحة الرئيسية تعرض كل المجموعات التي أنشأها المستخدم أو انضم إليها، مع رصيده في كل مجموعة
- منشئ المجموعة فقط يستطيع حذفها (تُحذف مصاريفها معها)

**لوحة المجموعة**
- **المصاريف الإجمالية** بمدى زمني: شهر (افتراضي) · ٣ · ٦ · ٩ أشهر · سنة · الكل
- **الفلوس اللي لي** و **الفلوس اللي علي** بعد **التسوية الصافية**: ما دفعه كل شخص يُطرح من حصته، فإذا دفع كل واحد حصته لا يظهر أي دين
- **تقفيل الحساب**: أقل عدد من التحويلات (فلان يحوّل لفلان مبلغ كذا) مع زر «تم الدفع» ورسالة تأكيد، وسجل تسويات قابل للتراجع
- **مشاركة الوضع في واتساب**: تقرير مختصر بالإجمالي والتحويلات المطلوبة
- **الإحصائيات**: مخطط دائري للمصاريف حسب الفئة بالمبلغ والنسبة (شهر · ٣ · ٦ · ٩ أشهر · سنة)
- الخروج من المجموعة، وإزالة الأعضاء من المنشئ — دون حذف مصاريفهم أو ديونهم

**المصاريف**
- الفئة **أو** الوصف (أحدهما إلزامي — يُسمّى المصروف باسم الفئة إذا تُرك الوصف فارغاً)
- **من دفع**، المشاركون من أعضاء المجموعة (+ ضيوف من خارجها)
- تقسيم بالتساوي (دقيق بالهللة) أو مخصص مع شريط تحقق
- **تعديل المصروف** من منشئه بعد حفظه
- المبالغ بـ **رمز الريال السعودي الجديد** (خط saudi_riyal، مع «ر.س» احتياطياً)

**عام**
- **الوضع الغامق** من الإعدادات (ويتبع مظهر الجهاز افتراضياً)
- مزامنة لحظية بين الأعضاء + عمل دون اتصال
- واجهة RTL عربية متجاوبة، قابلة للتثبيت كتطبيق
- **وضع تجريبي** ببيانات محلية: أضف `?demo` للرابط

## 🗄 البيانات في Firestore

| المسار | المحتوى |
|---|---|
| `users/{uid}` | `name`, `phone`, `email`, `avatarColor` |
| `groups/{CODE}` | `name`, `emoji`, `createdBy`, `members[]`, `memberInfo{uid → name/phone/avatarColor}` |
| `groups/{CODE}/settlements/{id}` | `from`, `to`, `amount`, `fromName`, `toName`, `createdBy`, `createdAt` |
| `groups/{CODE}/expenses/{id}` | `title`, `totalAmount`, `category`, `paidByUserId`, `createdBy`, `participants[]`, `splitMethod`, `note`, `createdAt` |

**الدخول برقم الجوال:** Firebase لا يدعم "جوال + كلمة مرور" مباشرة، لذلك يُربط كل رقم بحساب Email/Password داخلي بالشكل `966501234567@phone.qatta.app`. البريد الحقيقي (إن أُدخل) يُحفظ في الملف الشخصي فقط.
> ⚠️ استعادة كلمة المرور متاحة لحسابات البريد فقط؛ حسابات الجوال تحتاج SMS (خطة Blaze المدفوعة).

**قواعد الأمان** (`firestore.rules`):
- الملف الشخصي لصاحبه فقط
- المجموعة: يقرؤها أعضاؤها؛ يعدّلها ويحذفها منشئها؛ غير العضو الذي يملك الرمز يضيف نفسه فقط
- المصاريف: يقرؤها ويضيفها أعضاء المجموعة؛ أي عضو يسجّل الدفع؛ يحذفها منشئ المصروف أو منشئ المجموعة

## 🚀 النشر

1. **Firestore → Rules**: الصق محتوى `firestore.rules` ثم **Publish** (مطلوب عند كل تحديث للقواعد).
2. ارفع الملفات إلى المستودع (فرع `main`).
3. **Settings → Pages → Deploy from a branch → main / (root)**.
4. تأكّد أن `alsufyaniz.github.io` ضمن **Authentication → Settings → Authorized domains**.

**التشغيل محلياً:**
```bash
python3 -m http.server 8000
# http://localhost:8000/?demo
```
